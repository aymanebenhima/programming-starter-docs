# الشروط: اتخاذ القرارات

## كيف تتخذ أجهزة الكمبيوتر القرارات

في الحياة اليومية، تتخذ قرارات طوال الوقت بناءً على الموقف.
- **إذا (If)** كانت تمطر، **إذن** سآخذ مظلة.
- **وإلا (Else)**، سأرتدي نظارة شمسية.

يمكننا تعليم أجهزة الكمبيوتر اتخاذ هذه الأنواع من القرارات! في البرمجة، نسمي هذه **العبارات الشرطية (Conditional Statements)**. إنها تتحقق مما إذا كان شرط معين صحيحًا، ثم تقوم بمهمة بناءً على النتيجة.

## العبارة `if`

أبسط طريقة لاتخاذ قرار في الكود هي باستخدام العبارة `if`.

```js
let itIsRaining = true;

if (itIsRaining) {
  console.log('خذ مظلة!');
}
```

إليك كيفية بناء العبارة `if`:
1. تبدأ بالكلمة `if`.
2. بعد ذلك تأتي الأقواس `()`. بداخلها يوضع **الشرط** (سؤال إجابته نعم/لا أو صحيح/خطأ).
3. أخيرًا، هناك أقواس متعرجة `{}`. بداخل هذه الأقواس يوضع الكود الذي سيعمل **فقط إذا** كان الشرط `true` (صحيحًا).

إذا كان `itIsRaining` يساوي `false` (خطأ)، سيتخطى الكمبيوتر ببساطة الكود الموجود داخل الأقواس المتعرجة ولن يطبع أي شيء!

## العبارة `if...else`

ماذا لو أردنا أن يقوم الكمبيوتر بشيء آخر عندما يكون الشرط `false`؟ يمكننا إضافة عبارة `else` (وإلا)!

```js
let itIsRaining = false;

if (itIsRaining) {
  console.log('خذ مظلة!');
} else {
  console.log('ارتدِ نظارة شمسية!');
}
```

الآن، إذا كان الشرط `false`، يتخطى الكمبيوتر الكتلة الأولى من الكود ويشغل الكود الموجود داخل كتلة `else` بدلاً من ذلك. في هذه الحالة، سيطبع: `ارتدِ نظارة شمسية!`.

## طرح الأسئلة: معاملات المقارنة (Comparison Operators)

عادةً، لا تكون شروطنا مجرد متغير بسيط `true` أو `false`. نحن نريد مقارنة الأشياء. على سبيل المثال: "هل نتيجة اللاعب أعلى من 100؟"

لطرح هذه الأسئلة، نستخدم **معاملات المقارنة**:
- أصغر من: `<`
- أكبر من: `>`
- أصغر من أو يساوي: `<=`
- أكبر من أو يساوي: `>=`
- يساوي تماماً: `===`
- لا يساوي: `!==`

*لاحظ أن "يساوي" تستخدم ثلاث علامات يساوي `===`. تذكر أن علامة اليساوي الواحدة `=` تُستخدم فقط لوضع البيانات في صندوق المتغير!*

دعنا نرى هذا عمليًا:

```js
let hungerLevel = 8;

if (hungerLevel > 7) {
  console.log('حان وقت الأكل!');
} else {
  console.log('يمكننا أن نأكل لاحقاً!');
}
```
نظرًا لأن 8 أكبر من 7، سيطبع هذا الكود: `حان وقت الأكل!`.

## قرارات متعددة: `else if`

أحيانًا لا تكون الحياة مجرد A أو B. قد يكون هناك C و D و E!

إذا كان لدينا أكثر من نتيجتين محتملتين، يمكننا استخدام العبارات `else if` لربط القرارات معًا.

```js
let stopLight = 'أصفر';

if (stopLight === 'أحمر') {
  console.log('توقف!');
} else if (stopLight === 'أصفر') {
  console.log('تمهل!');
} else if (stopLight === 'أخضر') {
  console.log('انطلق!');
} else {
  console.log('احذر، إشارة غير معروفة!');
}
```

يقرأ الكمبيوتر من أعلى إلى أسفل. يتحقق من الشرط الأول (`'أحمر'`). وبما أنه خطأ، ينتقل إلى الشرط التالي (`'أصفر'`). وبما أن هذا صحيح، فإنه يشغل تلك الكتلة من الكود ويتجاهل الباقي تمامًا!

## التحقق من أشياء متعددة في وقت واحد (المعاملات المنطقية)

ماذا لو أردت الذهاب إلى الحديقة، ولكن **فقط إذا** كان الجو مشمسًا **و** كانت عطلة نهاية الأسبوع؟

يمكننا استخدام **المعاملات المنطقية (Logical Operators)** لدمج الشروط:
- **و (AND)** (`&&`): يجب أن يكون كلا الشرطين صحيحين.
- **أو (OR)** (`||`): يكفي أن يكون أحد الشرطين صحيحًا.

استخدام و (`&&`):
```js
let isSunny = true;
let isWeekend = true;

if (isSunny && isWeekend) {
  console.log('دعنا نذهب إلى الحديقة!');
}
```

استخدام أو (`||`):
```js
let day = 'السبت';

if (day === 'السبت' || day === 'الأحد') {
  console.log('استمتع بعطلة نهاية الأسبوع!');
}
```

## مراجعة

دعنا نراجع الشروط:
- **`if`** تتحقق من شرط وتُشغل كتلة من الكود إذا كان الشرط `true`.
- **`else`** توفر خطة بديلة افتراضية إذا كان الشرط `false`.
- **`else if`** تتيح لك التحقق من عدة شروط مختلفة على التوالي.
- **معاملات المقارنة** (مثل `>`، `<`، `===`) تساعدك في مقارنة القيم.
- **المعاملات المنطقية** (`&&` لـ و، `||` لـ أو) تتيح لك دمج عدة شروط معًا.
