# الشروط: اتخاذ القرارات

## كيف تتخذ أجهزة الكمبيوتر القرارات

في الحياة اليومية، تتخذ قرارات طوال الوقت بناءً على الموقف.
- **إذا (If)** كانت تمطر، **إذن** سآخذ مظلة.
- **وإلا (Else)**، سأرتدي نظارة شمسية.

يمكننا تعليم أجهزة الكمبيوتر اتخاذ هذه الأنواع من القرارات! في الكود الزائف، نسمي هذه **العبارات الشرطية (Conditional Statements)**. إنها تتحقق مما إذا كان شرط معين صحيحًا، ثم تقوم بمهمة بناءً على النتيجة.

## العبارة `IF ... THEN`

أبسط طريقة لاتخاذ قرار هي باستخدام عبارة `IF`.

```pseudo
SET is_raining TO TRUE

IF is_raining EQUALS TRUE THEN
  PRINT "خذ مظلة!"
END IF
```

إليك كيفية بناء هذه العبارة:
1. تبدأ بكلمة `IF` (إذا).
2. بعد ذلك يأتي **الشرط** (`is_raining EQUALS TRUE`). هذا سؤال إجابته نعم/لا.
3. ثم تأتي كلمة `THEN` (إذن). ستعمل التعليمات الموجودة بالداخل **فقط إذا** كان الشرط صحيحًا.
4. ننهي الكتلة بـ `END IF` ليعرف الكمبيوتر أين ينتهي القرار.

إذا كان `is_raining` هو `FALSE`، سيتخطى الكمبيوتر ببساطة الكود الموجود بالداخل ولن يطبع أي شيء!

## العبارة `IF ... THEN ... ELSE`

ماذا لو أردنا أن يقوم الكمبيوتر بشيء آخر عندما يكون الشرط خاطئًا؟ يمكننا إضافة عبارة `ELSE` (وإلا)!

```pseudo
SET is_raining TO FALSE

IF is_raining EQUALS TRUE THEN
  PRINT "خذ مظلة!"
ELSE
  PRINT "ارتدِ نظارة شمسية!"
END IF
```

الآن، إذا كان الشرط خاطئًا، يتخطى الكمبيوتر الكتلة الأولى ويشغل الكود الموجود داخل كتلة `ELSE` بدلاً من ذلك. في هذه الحالة، سيطبع: `ارتدِ نظارة شمسية!`.

## طرح الأسئلة: معاملات المقارنة

عادةً، لا تكون شروطنا مجرد متغير بسيط `TRUE` أو `FALSE`. نحن نريد مقارنة الأشياء. على سبيل المثال: "هل نتيجة اللاعب أعلى من 100؟"

لطرح هذه الأسئلة، نستخدم **معاملات المقارنة (Comparison Operators)**:
- `<` : أصغر من
- `>` : أكبر من
- `<=` : أصغر من أو يساوي
- `>=` : أكبر من أو يساوي
- `EQUALS` (أو `==`) : يساوي تماماً
- `NOT EQUALS` (أو `!=`) : لا يساوي

دعنا نرى هذا عمليًا:

```pseudo
SET hunger_level TO 8

IF hunger_level > 7 THEN
  PRINT "حان وقت الأكل!"
ELSE
  PRINT "يمكننا أن نأكل لاحقاً!"
END IF
```
نظرًا لأن 8 أكبر من 7، سيطبع هذا الكود: `حان وقت الأكل!`.

## قرارات متعددة: `ELSE IF`

أحيانًا لا تكون الحياة مجرد أبيض أو أسود. قد تكون هناك خيارات متعددة!

إذا كان لدينا أكثر من نتيجتين محتملتين، يمكننا ربط القرارات معًا باستخدام `ELSE IF`.

```pseudo
SET stop_light TO "yellow"

IF stop_light EQUALS "red" THEN
  PRINT "توقف!"
ELSE IF stop_light EQUALS "yellow" THEN
  PRINT "تمهل!"
ELSE IF stop_light EQUALS "green" THEN
  PRINT "انطلق!"
ELSE
  PRINT "احذر، إشارة غير معروفة!"
END IF
```

يقرأ الكمبيوتر من أعلى إلى أسفل. يتحقق من الشرط الأول (`"red"`). وبما أنه خطأ، ينتقل إلى الشرط التالي (`"yellow"`). وبما أن هذا صحيح، فإنه يشغل تلك الكتلة من الكود ويتجاهل الباقي تمامًا!

## التحقق من أشياء متعددة في وقت واحد (المعاملات المنطقية)

ماذا لو أردت الذهاب إلى الحديقة، ولكن **فقط إذا** كان الجو مشمسًا **و** كانت عطلة نهاية الأسبوع؟

يمكننا استخدام **المعاملات المنطقية (Logical Operators)** لدمج الشروط:
- **AND (و)** : يجب أن يكون كلا الشرطين صحيحين.
- **OR (أو)** : يكفي أن يكون أحد الشرطين صحيحًا.

استخدام `AND`:
```pseudo
SET is_sunny TO TRUE
SET is_weekend TO TRUE

IF is_sunny EQUALS TRUE AND is_weekend EQUALS TRUE THEN
  PRINT "دعنا نذهب إلى الحديقة!"
END IF
```

استخدام `OR`:
```pseudo
SET day TO "Saturday"

IF day EQUALS "Saturday" OR day EQUALS "Sunday" THEN
  PRINT "استمتع بعطلة نهاية الأسبوع!"
END IF
```

## مراجعة

دعنا نراجع الشروط:
- **`IF ... THEN`** تتحقق من شرط وتُشغل كتلة من الكود إذا كان الشرط صحيحًا.
- **`ELSE`** توفر خطة بديلة افتراضية إذا كان الشرط خاطئًا.
- **`ELSE IF`** تتيح لك التحقق من عدة شروط مختلفة على التوالي.
- **معاملات المقارنة** (مثل `>`، `<`) تساعدك في مقارنة القيم.
- **المعاملات المنطقية** (`AND`، `OR`) تتيح لك دمج عدة شروط معًا.
