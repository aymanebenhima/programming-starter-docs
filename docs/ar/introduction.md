# مقدمة في جافا سكريبت

## ما هي جافا سكريبت؟

مرحبًا بك في عالم البرمجة! إذا لم يكن لديك أي خبرة سابقة في كتابة الأكواد، فأنت في المكان الصحيح.

تخيل أن موقع الويب يشبه المنزل:
- **HTML** هو الهيكل (الجدران والغرف).
- **CSS** هو التصميم (الطلاء والديكور).
- **JavaScript** هي الكهرباء والسباكة. إنها تجعل المنزل "حيًا" وتفاعليًا!

جافا سكريبت هي لغة قوية تستخدمها معظم متصفحات الويب الحديثة. تسمح لك بإنشاء إجراءات ديناميكية على مواقع الويب، مثل النقر فوق زر لإظهار نافذة منبثقة، أو تحريك الصور، أو التحقق مما إذا كانت كلمة المرور صحيحة.

## وحدة التحكم (Console): أداة المطور الخاصة بك

عندما تكتب الكود، يكون الكثير من العمل الذي يقوم به الكمبيوتر غير مرئي. ولكن ماذا لو أردت رؤية ما يفعله الكمبيوتر؟

هنا يأتي دور **وحدة التحكم (Console)**! وحدة التحكم عبارة عن لوحة مخفية في متصفح الويب الخاص بك يستخدمها المطورون لرؤية الرسائل والتحقق من الأخطاء.

في جافا سكريبت، نستخدم أمرًا يسمى `console.log()` لطباعة الرسائل في هذه اللوحة المخفية. أي شيء تضعه بين الأقواس `()` سيظهر على الشاشة.

```js
// هذا سيطبع الرقم 5 في وحدة التحكم
console.log(5);

// هذا سيطبع رسالة ترحيب
console.log('مرحباً بالعالم!');
```

*ملاحظة: قد تلاحظ الفاصلة المنقوطة `;` في النهاية. فكر فيها كالنقطة في نهاية الجملة. إنها تخبر الكمبيوتر أن تعليماتك قد انتهت!*

## التعليقات (Comments): ملاحظات للبشر

في بعض الأحيان، قد ترغب في ترك ملاحظة في الكود الخاص بك لنفسك أو لأشخاص آخرين، لكنك لا تريد أن يقرأها الكمبيوتر. تُسمى هذه الملاحظات **التعليقات**. يتجاهلها الكمبيوتر تمامًا!

هناك طريقتان لكتابة التعليقات:

**1. تعليق على سطر واحد:** استخدم شرطتين مائلتين `//`. يتم تجاهل كل شيء بعدهما في ذلك السطر.

```js
// هذه ملاحظة لي. لن يقرأ الكمبيوتر هذا!
console.log(10); 
```

**2. تعليق متعدد الأسطر:** استخدم `/*` للبدء و `*/` للإنهاء. هذا رائع للملاحظات الطويلة.

```js
/*
  هذه ملاحظة طويلة.
  يمكن أن تأخذ أسطر متعددة.
  لن ينفذ الكمبيوتر أيًا من هذا!
*/
```

## أنواع البيانات (Data Types): أنواع المعلومات

في الحياة الواقعية، نتعامل مع أنواع مختلفة من المعلومات: كلمات، أرقام، وإجابات نعم/لا. البرمجة تعمل بنفس الطريقة تمامًا!

في جافا سكريبت، نصنف المعلومات إلى **أنواع بيانات** مختلفة. إليك الأنواع الأساسية والمهمة للمبتدئين:

- **الرقم (Number)**: أي رقم، بكسور عشرية أو بدونها. مثال: `4`، `15`، `23.42`.
- **السلسلة النصية (String)**: أي نص، مثل الحروف، الكلمات، أو الجمل. يجب أن تضع النصوص بين علامتي اقتباس حتى يعرف الكمبيوتر أنه نص. مثال: `'مرحباً'`، `"أنا أحب البرمجة"`.
- **المنطقية (Boolean)**: هذا مفتاح بسيط لـ "التشغيل" أو "الإيقاف". يحتوي فقط على قيمتين محتملتين: `true` (نعم/صحيح) أو `false` (لا/خطأ). لا تستخدم علامات الاقتباس للقيم المنطقية!
- **فارغ (Null)**: هذا يعني ببساطة "لا شيء" أو "فارغ" عن قصد.
- **غير محدد (Undefined)**: هذا يعني أنه لم يتم تعيين قيمة بعد. الكمبيوتر يعرف أن هناك شيئًا موجودًا، لكنه لا يعرف ما هو.

```js
console.log('هذه سلسلة نصية لأن بها علامات اقتباس!');
console.log(40); // هذا رقم. لا توجد علامات اقتباس!
console.log(true); // هذه قيمة منطقية.
```

## الرياضيات في الكود (المعاملات الحسابية)

أجهزة الكمبيوتر هي في الأساس آلات حاسبة عملاقة. يمكنك القيام بالعمليات الحسابية في جافا سكريبت باستخدام رموز بسيطة تُسمى **المعاملات (Operators)**:

- جمع: `+`
- طرح: `-`
- ضرب: `*`
- قسمة: `/`

```js
console.log(3 + 4); // يطبع 7
console.log(5 - 1); // يطبع 4
console.log(4 * 2); // يطبع 8
console.log(9 / 3); // يطبع 3
```

## دمج الكلمات معًا (String Concatenation)

الرمز `+` ليس للرياضيات فقط! إذا استخدمت `+` مع **النصوص (Strings)**، فإنه يدمج الكلمات معًا. يُسمى هذا **الدمج (Concatenation)**.

```js
console.log('مر' + 'حباً'); // يطبع 'مرحباً'
console.log('أنا أحب ' + 'البرمجة.'); // يطبع 'أنا أحب البرمجة.'
```

لاحظ المسافة بعد كلمة "أحب ". الكمبيوتر يدمج النص تمامًا كما تكتبه، لذا إذا كنت تريد مسافة بين الكلمات، يجب عليك كتابتها داخل علامات الاقتباس!

## مراجعة

دعنا نلخص ما تعلمته:
- **جافا سكريبت** تجعل مواقع الويب تفاعلية.
- استخدم `console.log()` لطباعة الرسائل ورؤية ما يفعله الكود الخاص بك.
- اكتب **التعليقات** باستخدام `//` أو `/* ... */` لترك ملاحظات يتجاهلها الكمبيوتر.
- **أنواع البيانات** الأساسية هي الأرقام، النصوص (بين علامات اقتباس)، والقيم المنطقية (`true` أو `false`).
- يمكنك القيام بالعمليات الحسابية باستخدام `+`، `-`، `*`، و `/`.
- يمكنك دمج النصوص معًا باستخدام الرمز `+`.
