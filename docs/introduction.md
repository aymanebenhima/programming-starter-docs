# Introduction to Pseudo Code

## What is an Algorithm?

Welcome to the world of programming! If you have zero experience in coding, you are in the right place. 

Before we write code for computers, we need to understand how to solve problems. An **Algorithm** is simply a step-by-step list of instructions used to complete a task or solve a problem.

Think of a recipe for baking a cake:
1. Gather ingredients.
2. Mix the flour and sugar.
3. Bake in the oven for 30 minutes.

If you follow the algorithm perfectly, you get a cake! Computers work the exact same way. They are incredibly fast, but they are not smart. They need *you* to give them exact, step-by-step instructions.

## What is Pseudo Code?

**Pseudo Code** (fake code) is a way to write down algorithms using plain human language mixed with some simple structural rules. 

Why use it? 
- It ignores strict grammar rules (like missing a semicolon `;`).
- It helps you focus on **logic** and **problem-solving**.
- Once your pseudo code works, it can be easily translated into *any* real programming language (like Python, JavaScript, or C).

## The Output: Displaying Information

When an algorithm runs, we often want it to show us a result. In pseudo code, we use the word `PRINT` (or `DISPLAY`) to tell the computer to show a message on the screen.

```pseudo
PRINT "Hello, World!"
PRINT 5
```

When the computer reads the above algorithm, it will show the words `Hello, World!` followed by the number `5` on the screen. 

## Data Types: The Kinds of Information

In real life, we deal with different kinds of information: words, numbers, and yes/no answers. Programming is exactly the same! 

We classify information into different **Data Types**. Here are the most basic ones:

- **Number**: Any number, with or without decimals. Example: `4`, `15`, `23.42`.
- **String**: Any text, like letters, words, or sentences. You MUST wrap strings in quotes so the computer knows it's text. Example: `"Hello"`, `"I love coding"`.
- **Boolean**: This is a simple "on" or "off" switch. It only has two possible values: `TRUE` (yes) or `FALSE` (no). 

## Math in Pseudo Code

Computers are essentially giant calculators. You can do math in pseudo code using basic symbols:

- Add: `+`
- Subtract: `-`
- Multiply: `*`
- Divide: `/`

```pseudo
PRINT 3 + 4   // Prints 7
PRINT 5 - 1   // Prints 4
PRINT 4 * 2   // Prints 8
PRINT 9 / 3   // Prints 3
```

## Review

Let’s recap what you've learned:
- An **Algorithm** is a step-by-step list of instructions to solve a problem.
- **Pseudo Code** is a way to write algorithms in plain English to focus on logic rather than strict syntax.
- Use `PRINT` to show messages or results.
- The basic **Data Types** are Numbers, Strings (text in quotes), and Booleans (`TRUE` or `FALSE`).
- You can do math using standard operators like `+`, `-`, `*`, and `/`.
